AgriShif portable landing page

This folder is a standalone, static replica of the AgriShif landing page.
It has no build step, package installation, server, or external image/font dependency.

To view it, open index.html in a web browser.
To share or move it, copy the entire portable-landing-page folder and keep its assets folder alongside the HTML file.

The navigation buttons link to sections on this page. The explorer itself is not part of this static copy.
